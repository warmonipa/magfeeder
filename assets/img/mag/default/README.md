# Default Mag portraits

46 transparent 900 × 900 WebP renders, copied byte-for-byte from Haven Wiki's assets/img/mag/default/. Original PSOBB models/textures, without player colour modulation. Cameras are individually calibrated to the chart references; these are Blender previews, not game screenshots or the named White colour. Camera-relative sun and ambient lighting keeps brightness close to the original textures (brightened on 2026-09-24 from the earlier, darker fixed studio lights; parameters in manifest.json `lighting`). Agastya uses embedded animation frame 26. Agastya, Garuda, Marica and Rati retain documented outline differences accepted in this batch. See manifest.json for resource hashes, model/texture slots, cameras, lighting and output hashes.

Update this directory together with the Wiki's accepted default portrait set. This independent simulator does not use the Wiki chart's cyan recolouring inputs.
